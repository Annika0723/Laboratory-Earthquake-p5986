# Laboratory-Earthquake-p5986
##  Overview

Machine-learning approaches have become powerful tools for laboratory earthquake studies, as acoustic emissions (**AE**) generated during stick-slip contain rich information about the fault state. Earlier work utilized **Random Forest**, followed by **XGBoost** and more recent **deep learning models**, to estimate mechanical behavior from acoustic data. 

However, while many previous datasets were relatively repetitive or quasi-periodic, the **`p5986` experiment** studied here lies near the frictional instability boundary—producing strongly aperiodic stick-slip cycles and scattered stress drops. This makes `p5986` a stringent benchmark for testing whether applying machine learning in passive AE signals can still accurately predict shear stress evolution in irregular laboratory earthquakes.
